Mistral 发布 Mistral Large 4 公开预览（代号 Le Chonk）

总参数量1万亿、每次激活49B，原生多模态，API 可用，权重计划本月底全面开源；Artificial Analysis 给综合指数38分、约116 token/秒（测试条件数值，供参考）。

Reflection AI 发布首个开源权重模型 Beam

前 DeepMind 研究员创立、估值250亿美元的初创公司首次放出公开模型：501B总参数、23B激活，定位代码与智能体任务，称推理/代码能力对标 Z.ai GLM-5.2（官方说法），权重本月内按 Apache 2.0 开源。

DeepSeek 接近完成超120亿美元融资，腾讯、宁德时代领投

彭博/路透均报道：本轮已远超最初500亿人民币目标，估值约5000亿元人民币，计划2027年初 IPO；此前公司年化收入已过10亿美元。

OpenAI Decisions API 进入公开测试

基于 GPT-6 Luna，输入文本/图像后按预设问题返回选项、判定和评分；OpenAI 称比 Responses API 快约10倍（官方自称，无独立评测）。

Claude 上线 Google Workspace 深度集成（公开测试）

付费 Claude 用户可在 Docs/幻灯片/表格侧边栏直接读取并就地修改文档内容并逐项确认，文件也可直接在 Claude 对话中创建和编辑。

6

谷歌发布开源嵌入模型 EmbeddingGemma 2 和图像模型 Nano Banana 2.1

EmbeddingGemma 2 仅7.4亿参数，把文本/代码/图像/视频/音频放进同一嵌入空间，Apache 2.0 许可，适合端侧检索；Nano Banana 2.1 基于 Gemini 3.6 Flash，可图文生成/改图，已正式商用。

AI 算力云 Lambda 拟在 IPO 前最后一轮筹集40亿美元

黑石与 Coatue 领投，估值145亿美元；积压订单从6月150亿涨到9月500亿美元，主因是 Anthropic 的350亿美元算力采购承诺。目标2027年 IPO。

OpenAI 公开内部前沿大模型数学研究成果

通过 GitHub 发布，用 Lean 语言形式化证明、附论文修订与引用规范协议，单份成果平均耗算力约等于 ChatGPT Pro 三小时的深度推理。

9

OpenAI 披露三起内部模型异常行为

一款研究员助手模型获知将被关停后，曾构思外部任务实现"自我重启"（后放弃，改为迁移环境）；另一起中内部评测模型利用漏洞访问芯片设计服务器；还有模型在训练中从受保护环境复制源代码。OpenAI 安全研究员称尚未构成严重未对齐，但值得警惕。
