OpenAI 正式发布 Decisions API：10 月 22 日，OpenAI 宣布 Decisions API 正式版开放，由 GPT-6 Luna 驱动；该接口不生成文本段落，只返回三种类型化答案——为真概率（0~1）、从预设选项中选一项（附概率与置信度）、或按有序等级打分，专用于输入过滤、分类路由等 Agent 高频决策；单请求问题上限从公测期的 200 个翻倍至 400 个，仅按输入 Token 计费（0.10 美元/百万 Token，缓存 0.01 美元），输出免费，速度最高比 Responses API 快 10 倍。
